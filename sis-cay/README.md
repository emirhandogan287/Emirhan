# SİS · Kaçkar Çayı

[scroll-craft](https://github.com/nateherkai/scroll-craft) motoru ve tasarım yöntemiyle hazırlanmış, kaydırmaya dayalı tanıtım sitesi. SİS kurgusal bir çay markasıdır.

Çalıştırmak için bu klasörde bir statik sunucu açman yeterli:

```bash
python3 -m http.server 4500   # sonra http://localhost:4500
```

- `index.html`: sayfa (bütün görseller kodla çizilen SVG; harici görsel yok)
- `scrollcraft.js` / `scrollcraft.css`: scroll-craft motoru (değiştirilmedi)
- `BRIEF.md`: tasarım kararları, duygu eğrisi, skor
